# Visual Direction

## Mood

따뜻하지만 절제된 모바일 청첩장. 장식보다 사진, 날짜, 장소, 행동 버튼이 먼저 읽혀야 한다.

## First View

- 커버 이미지는 실제 커플 또는 예식 분위기를 보여주는 이미지를 사용한다.
- 이름과 날짜는 첫 화면에서 명확해야 한다.
- 첫 화면에 다음 섹션의 시작이 살짝 보이도록 높이를 조절한다.

## Interaction Feel

- 긴 설명 대신 짧은 라벨과 명확한 버튼을 사용한다.
- RSVP와 방명록은 제출 상태가 즉시 보인다.
- 지도와 길찾기는 정보 탐색이 아니라 실제 이동을 돕는 기능으로 다룬다.

## Avoid

- 섹션마다 과한 카드 박스
- 장식용 gradient orb 또는 추상 배경
- 한 색상 계열만 반복하는 팔레트
- 텍스트가 이미지나 지도 위에서 읽기 어려운 배치
