# Mobile Invitation Product Spec

## User

하객은 모바일 브라우저에서 청첩장을 열고, 예식 정보를 확인하고, 축하 메시지나 참석 여부를 남긴다.

## Happy Path

1. 하객이 공유 링크를 연다.
2. 커버에서 신랑/신부 이름과 날짜를 확인한다.
3. 인사말, 소개, 달력, 갤러리를 스크롤로 본다.
4. RSVP를 제출한다.
5. 방명록을 작성한다.
6. 오시는 길에서 Naver Maps 지도와 네이버지도 길찾기 링크를 확인한다.
7. 필요한 경우 계좌번호를 복사한다.

## Required Sections

- 메인 커버
- 초대 문구 또는 글귀
- 인사말
- 신랑/신부 소개와 연락처
- 달력과 D-day
- 갤러리
- RSVP
- 화환 안내
- 계좌 안내
- 방명록
- 오시는 길
- 주차/안내사항
- 엔딩

## Out Of Scope

- 게스트스냅
- 게스트 사진 업로드
- 섹션 목차와 위치 인덱스
- 방문 분석과 접근 로그
- 템플릿 편집기

## RSVP Behavior

- 필수값은 측 구분, 참석 여부, 이름, 개인정보 동의다.
- 참석하는 경우 식사 여부를 받는다.
- 동행인 수는 0 이상의 정수다.
- 제출 중에는 버튼을 비활성화한다.
- 성공 시 제출 완료 상태를 보여준다.
- 실패 시 입력값을 유지하고 재시도를 허용한다.

## Guestbook Behavior

- 이름과 메시지를 필수로 받는다.
- 작성 성공 후 공개 목록을 갱신한다.
- 공개 목록은 visible이고 deleted가 아닌 항목만 보여준다.
- 목록 조회 실패는 빈 상태와 구분한다.

## Map Behavior

- 임베디드 지도는 Naver Maps로 렌더링한다.
- 장소 좌표에 마커를 표시한다.
- 지도 실패 시 장소명, 주소, 네이버지도 링크를 보여준다.
- Kakao Map은 사용하지 않는다.

## Acceptance Criteria

- 모바일 360px 폭에서 모든 필수 섹션이 가로 스크롤 없이 보인다.
- 게스트스냅과 섹션 인덱스 UI가 없다.
- RSVP 제출 성공과 실패 상태가 모두 검증된다.
- 방명록 작성 후 목록에 새 글이 보인다.
- Naver Maps 지도 또는 실패 대체 UI가 보인다.
- 네이버지도 길찾기 링크가 실제 장소로 연결된다.
