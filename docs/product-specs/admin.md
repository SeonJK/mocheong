# Admin Product Spec

## User

관리자는 신랑/신부 또는 운영자다. 비밀번호로 로그인해 RSVP와 방명록을 확인한다.

## Happy Path

1. 관리자가 `/admin`에 접속한다.
2. `ADMIN_PASSWORD`를 입력한다.
3. RSVP 목록을 확인한다.
4. RSVP CSV를 다운로드한다.
5. 방명록 목록을 확인한다.
6. 부적절한 방명록을 숨김 또는 삭제 처리한다.

## Authentication

- 단일 관리자 비밀번호를 사용한다.
- 성공 시 HttpOnly 세션 쿠키를 설정한다.
- 실패 시 관리자 데이터는 응답하지 않는다.

## RSVP Management

- 최신순 목록을 기본으로 보여준다.
- 측 구분, 참석 여부, 식사 여부, 이름, 연락처, 동행인, 메모, 생성일을 볼 수 있다.
- CSV 다운로드는 현재 저장된 RSVP 전체를 포함한다.

## Guestbook Management

- 공개/숨김/삭제 상태를 모두 볼 수 있다.
- 숨김은 공개 목록에서 제외한다.
- 삭제는 v1에서 soft delete로 처리한다.
- 숨김과 삭제 액션은 확인 단계를 거친다.

## Out Of Scope

- 다중 관리자 계정
- 역할별 권한
- 관리자 활동 로그
- RSVP hard delete

## Acceptance Criteria

- 인증 전에는 관리자 데이터가 보이지 않는다.
- 잘못된 비밀번호는 오류를 표시하고 세션을 만들지 않는다.
- RSVP 목록과 CSV 다운로드가 동작한다.
- 방명록 숨김 후 공개 목록에서 사라진다.
- 방명록 삭제 후 공개 목록에서 사라지고 관리자에는 삭제 상태로 남는다.
