# Source Site Analysis Reference

분석 대상: `https://salondeletter.com/w/lls3oogcpr`

## Useful Patterns To Keep

- 모바일 단일 페이지 청첩장 흐름
- 커버, 글귀, 인사말, 소개, 달력, 갤러리, RSVP, 계좌, 방명록, 오시는 길, 안내사항, 엔딩 구조
- 공유용 OG metadata
- 검색 노출 방지를 위한 noindex 계열 metadata
- Naver Maps 기반 지도 영역
- 외부 길찾기 버튼

## Remove Or Avoid

- 게스트스냅 섹션
- 게스트스냅 업로드 링크
- 섹션 목차와 위치 이동 인덱스
- 햄버거 메뉴형 섹션 바로가기
- 방문 로그 또는 분석 기능

## Adaptation Notes

- 원본 사이트의 기능 밀도를 그대로 복제하지 않는다.
- 사용자에게 필요한 RSVP, 방명록, 장소 안내에 집중한다.
- 지도는 Naver Maps를 명시적 표준으로 둔다.
- 카카오 관련 기능은 외부 길찾기 링크 수준으로만 제한한다.
